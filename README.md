# Kashipur Tarun Projontho - Website

A responsive website for Kashipur Tarun Projontho organization, focusing on education, environmental initiatives, and community development.

## Project Structure

├── gallery-tree-planting.html # Tree planting gallery
├── demo-gallery-navigation.html # Gallery navigation demo
├── assets/
│   ├── css/
│   │   ├── styles.css                    # Main stylesheet
│   │   ├── gallery.css                   # Gallery specific styles
│   │   ├── gallery-tree-planting.css    # Tree planting gallery styles

## Features

- **Responsive Design**: Works on all device sizes
- **Modern UI**: Clean, professional design with smooth animations
- **Image Galleries**: Interactive image sliders and galleries
- **Team Section**: Dedicated page for team members
- **Events Section**: Comprehensive events listing
- **Contact Information**: Easy-to-find contact details

## Pages

1. **Home (index.html)**: Main landing page with organization overview
2. **Team (team.html)**: Team members and leadership information
3. **Events (events.html)**: Current and past events
4. **Event Gallery (event-gallery.html)**: Photo gallery of events
5. **Tree Planting Gallery (gallery-tree-planting.html)**: Specialized gallery for tree planting events
6. **Demo Gallery (demo-gallery-navigation.html)**: Gallery navigation demonstration

## Technologies Used

- HTML5
- CSS3 (with modern features like Flexbox, Grid, and CSS Variables)
- Vanilla JavaScript
- Font Awesome Icons
- Responsive design principles

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

## Development

This is a static website that can be served from any web server. No build process or special dependencies required.
